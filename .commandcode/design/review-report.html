// PRIORITY ISSUES
P0

The design answers "what does Murat's site look like," not "who is Jay Bell"

Fonts, token names, canvas, hero grammar, button labels, and work-list pattern are all inherited. Swap the names back and nothing breaks. "I build software that makes a difference" could belong to any developer on the internet, and the rows below it do not prove it. Murat's claim is specific to him and his work list proves it; that is the difference between a reference and a fork.

FIX: /design voice to pick Jay's lane, then rewrite the hero around something only he can say: ng-conf's official podcast, 10 years as CTO of a platform charities run on, Angular GDE and Nx Champion. The claim must be provable by the rows beneath it.
P0

The most differentiated facts of Jay's career are flattened into identical rows

ng-conf's official podcast, a Warhammer 40k companion app, the GDE/Nx community role, a decade as CTO of a fundraising platform, and a YouTube show all get the same 5-line row, the same 3 gray pills, the same 10px link. No episode counts, no donation volume, no talk counts, no face, no artwork. A visitor leaves knowing Jay's job titles and nothing about Jay.

FIX: /design relayout the homepage. One piece of evidence in the hero (a number, a face, the podcast mark). Let Trellis and the podcast be visually bigger than the rest. Bring in real artifacts: artwork, counts, years, a photo.
P1

Light-mode accent fails WCAG contrast everywhere it appears as text

#9487d8 on #f7f6f3 computes to 2.89:1, used for the 11px kicker, 10px blog dates, lede links, and the hero's italic emphasis. All fail AA (4.5:1 normal, 3:1 large). ink3 at 3.87:1 fails on the 10-13px meta text it styles. Dark mode passes across the board, so light mode was never checked. The source site's orange passes at 4.19:1.

FIX: /design recolor. Split the accent role: a darker lavender for text-on-paper (~#6a5aae passes 4.5:1), the light lavender reserved for fills and dark mode. Darken ink3 in light mode.
P1

Work rows advertise clickability they do not have

Each "Things I'm up to" row animates background and padding on hover, the universal signal for "this row is a link." Only the 10px "→" text at the far right navigates. The affordance lies, and the real links sit far under the 44px touch-target floor.

FIX: /design interaction. Make whole rows navigate or remove the hover theater. Inert rows should look inert. Link targets need real hit areas.
P2

Focus visibility is the browser default

Tabbing shows Chrome's stock 1px blue outline (rgb(0,95,204)) on every control. It clashes with the lavender palette and sits below the 2-3px / 3:1 bar. No :focus-visible styling exists in main.css. The working skip link makes the omission everywhere else more conspicuous.

FIX: /design interaction. Add a :focus-visible ring in the accent (2px, offset 2-3px) so keyboard users get a ring that belongs to this system.
P2

Dead and sloppy interaction code ships in the page

The blog card's "Read →" span carries group-hover:translate-x-1 but the anchor has no group class, so the rule can never fire. scroll-behavior: smooth is global with no prefers-reduced-motion guard. theme-color is hard-coded to #9487d8 regardless of active theme.

FIX: /design finish. Add group or delete the class, gate smooth scrolling behind a reduced-motion media query, set theme-color per scheme.
// WHAT'S WORKING

Dark mode done properly

Class-based tokens, localStorage persistence, and a no-flash inline bootstrap before first paint. Contrast passes across the board. The most authored thing on the site.

The skeleton is readable

860px measure, 15px base, 1.6 leading, restrained type scale. The section-rule headers are a genuine improvement over the source.

Real data flows through it

Blog and podcast merge on-site posts with Advocu/GDE activity into a dated stream. Infrastructure the current design wastes.
